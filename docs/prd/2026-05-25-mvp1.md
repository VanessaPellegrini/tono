# PRD: Last Guitar - MVP 1

## Problema

Explorar escalas y acordes en guitarra o piano requiere conocimientos de teoria musical o apps complejas con curvas de aprendizaje altas. No existe una interfaz visual e intuitiva que permita experimentar con armonias en tiempo real usando distintos metodos de input.

## Solucion

Interfaz musical con sistema de ruedas duales: una rueda selecciona la tonalidad (circulo de quintas) y la otra muestra los 7 acordes diatonicos correspondientes. Tres modos de input (gamepad, pointer, webcam con hand tracking) con sonidos reales de guitarra y piano via Tone.js.

## Hipotesis

| # | Hipotesis | Metrica | Criterio de exito |
|---|-----------|---------|-------------------|
| H1 | El sistema de ruedas duales reduce la friccion para explorar progresiones | Tiempo hasta tocar la primera progresion de 3 acordes | < 30 segundos sin tutorial |
| H2 | Los 3 modos de input cubren distintas preferencias de usuario | Distribucion de uso entre modos | Ningun modo con < 10% de sesiones |
| H3 | Los samples reales aumentan la satisfaccion vs sintetizadores | NPS o feedback cualitativo | Rating > 4/5 en "calidad de sonido" |
| H4 | La app funciona sin instalacion ni backend | Tasa de exito de carga en browser | > 99% en Chrome/Edge |

## Scope MVP 1

| # | Feature | Prioridad |
|---|---------|-----------|
| 1 | Rueda de tonalidad (circulo de quintas, 12 segmentos) | P0 |
| 2 | Rueda de acordes diatonicos (7 segmentos, recalculo automatico) | P0 |
| 3 | 8 tipos de escala (Major, Minor, Harmonic Minor, Melodic Minor, Dorian, Mixolydian, Pentatonic Major, Pentatonic Minor) | P0 |
| 4 | Samples reales de guitarra (Emily) y piano (velocity layers) | P0 |
| 5 | Modo Dual Wheel (pointer/click) | P0 |
| 6 | Modo Joystick (gamepad DualSense) | P1 |
| 7 | Modo Webcam (MediaPipe Hands + hand tracking overlay) | P1 |
| 8 | Toggle de accidentales (#, natural, b) | P1 |
| 9 | Motor de audio polifonico con reverb y compresion | P0 |
| 10 | Deploy en Vercel como SPA sin backend | P0 |

## Lo que NO incluye

- Grabacion o exportacion de audio
- Persistencia de sesiones o configuracion de usuario
- Compartir progresiones (URLs, redes)
- Soporte mobile nativo (responsive basico nomas)
- Modulo de aprendizaje o tutoriales guiados
- Más instrumentos ademas de guitarra y piano
- Backend, autenticacion, base de datos

## Criterio de cierre

- [ ] Las 8 escalas generan acordes diatonicos correctos (tests pasando)
- [ ] Ambas ruedas se renderizan y responden a clicks en menos de 16ms
- [ ] Audio de guitarra y piano suena polifonicamente sin glitches perceptibles
- [ ] Modo Dual Wheel completamente funcional en Chrome y Edge
- [ ] Modo Joystick funciona con DualSense o gamepad generico
- [ ] Modo Webcam detecta manos y superpone pointers sobre las ruedas
- [ ] Deploy en Vercel carga sin errores en fresh session
- [ ] Tests unitarios pasan (`npm test` verde)
- [ ] Lighthouse Performance > 80

## Post-MVP Roadmap

- **MVP 2:** Grabacion de progresiones, exportacion MIDI/WAV, compartir via URL
- **MVP 3:** Modo aprendizaje con ejercicios guiados, visualizacion de digitacion en guitarra
- **MVP 4:** Soporte mobile con touch gestures, PWA offline, mas instrumentos (bajo, ukelele)
- **MVP 5:** Colaboracion en tiempo real, sala de jam多人via WebRTC
